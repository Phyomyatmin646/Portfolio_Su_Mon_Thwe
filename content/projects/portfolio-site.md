This portfolio was designed and built from scratch as a showcase of modern web development practices. It uses TanStack Start's file-based routing, Content Collections for type-safe markdown, and Netlify Image CDN for automatic image optimization.

Key technical decisions:
- **TanStack Start** for file-based routing and server rendering
- **Content Collections** for type-safe blog, project, and resume data
- **Netlify Image CDN** for on-demand, optimized image delivery
- **Tailwind CSS v4** with custom design tokens
